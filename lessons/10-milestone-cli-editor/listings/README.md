# Lesson 10 Milestone: CLI Editor

This is a milestone lesson requiring integration of multiple concepts.
For the Win32 port, students would implement:

- Console I/O with ReadConsoleA/WriteConsoleA
- Buffer management with dynamic arrays
- Input processing (arrow keys, editing commands)
- Screen updates with console APIs

Example listing would be a complete mini-editor (200+ lines).
For this port, see existing solutions/ for the full implementation pattern.
